# 指尖开花第二版

独立的本地 HTML 站点，用 22 个真实花朵开放视频控制主舞台，并保留照片卡和开花动效。

## 启动

最简单的方式是双击 `启动网站.cmd`，它会自动启动本地服务并打开浏览器。

也可以在本目录运行：

```powershell
node serve.mjs
```

浏览器打开 `http://127.0.0.1:5184/`。

## 交互

- 右手食指与拇指距离：控制花朵开合进度。
- 右手左右移动：切换花朵。
- 无摄像头时：拖动开合滑条、按空格播放、按 `P` 生成照片、方向键切花。
- “生成动效视频”会录制当前 Canvas 为 WebM；“生成花朵照片”可下载 PNG。
- 22 个花朵视频位于 `assets/flowers/videos/`，手势会直接控制当前 MP4 的时间轴；画面按完整视频画幅居中绘制。

MediaPipe、WASM 和手部模型均随站点本地提供，摄像头画面不会上传。
